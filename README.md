# 后室卡牌数值实验室

这是一个独立的三关 H5 数值测试原型，数据映射自 `后室Q版卡牌手游_试玩原型卡牌系统总表_V3.xlsx`。

## 当前包含

- 三关回合制战斗、波次、奖励和 Boss
- 表中基础卡、万能卡、合成卡和主要被动规则
- 木棍 + 工具包 + 工作台 -> 带刺球棒
- 打火机 + 能量饮料 + 工作台 -> 火焰喷射器
- 固定随机种子、调试倍率、跳过波次、事件日志导出
- 单体、多弹道、全体三种攻击分配方式
- 发射数量、逐弹道伤害取整、固定分母溅射与溅射向上取整
- 悬停卡牌时显示逐敌人伤害预览，暴击与击退结果可复现
- 实际伤害、溅射贡献、过量伤害分别统计
- 内置视频数值示例的公式校验
- 桌面和窄屏手机布局

## 打开方式

直接打开 `index.html` 即可试玩。也可以在本目录启动任意静态文件服务器后访问。

## 说明

敌人和三关参数是为了验证闭环设置的临时测试值，集中写在 `app.js` 的 `STAGES` 与 `ENEMY_TYPES` 配置中，后续可以根据正式数值表调整。

伤害模型调试区可以直接设置普通伤害加成、额外发射数量、溅射比例和溅射固定分母。点击“应用参数”会重置当前波次，以便使用相同敌人状态进行对照测试。
